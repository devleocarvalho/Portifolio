## ✨ About This Portfolio Project

This repository powers my personal portfolio website, combining a modern interactive UI with a full **DevSecOps CI/CD Security Pipeline**:

- 🌍 **100% Trilingual Architecture (`PT-BR`, `EN`, `ES`):** Instant language switching across all 35 web/SaaS projects, 11 cybersecurity technical dossiers, and the interactive project budget simulator.
- 🔍 **Technical Stack Details Modal:** Every project features a **"Detalhes / Details"** view detailing its full technology stack, architecture, and implementation highlights.
- 🛡️ **Dedicated Cybersecurity, Forensics &amp; DevSecOps Hub:** Interactive showcase covering 11 specialized projects (DevSecOps Supply Chain Pipelines, Zero Trust TLS 1.3 mTLS VPN, Linux/Mobile Hardening &amp; OWASP ZAP DAST, Financial HMAC Integrity Engines, OAuth 2.0 + PKCE Red/Blue Team IAM, VeraCrypt Digital Forensics, LSB Steganalysis, and Salted Hash Cryptanalysis) with downloadable official PDF reports.
- 🔒 **Hardened Serverless API &amp; Zero-Trust Headers:** Strict Content-Security-Policy (CSP), HSTS, anti-clickjacking headers, server-side Honeypot validation, HTML/CRLF sanitization, Mass Assignment protection, and per-IP rate limiting on `/api/contact`.
- ⚙️ **Automated DevSecOps Workflow (`.github/workflows/universal-audit.yml`):**
  1. **Secret Scanning:** Gitleaks across full commit history.
  2. **SAST:** Semgrep static code analysis.
  3. **SCA &amp; SBOM:** Trivy dependency scanning + CycloneDX SBOM generation.
  4. **IaC Audit:** Trivy configuration verification.
  5. **Automated AppSec Regression Suite (`npm test`):** 25 automated assertions in `scripts/test_security_audit.mjs`.
  6. **Blocking Quality Gate (`scripts/quality_gate.py`):** Enforces 0 Critical / 0 High findings.
